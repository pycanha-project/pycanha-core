3// src-private accumulators: GPU integer cells plus the host bookkeeping
4// needed to normalize them into results and compute statistics. Matrix
5// accumulators (VF counts, exchange fixed-point energy) come in two
6// layouts, one result:
7// - Dense: one num_slots x num_slots buffer, cells stay on the GPU.
8// - Tiled: a tile_rows x num_slots scratch buffer reused per row block;
9// cells stream into per-row host maps after every block.
10// Cells are integers, so both layouts produce bit-identical results for the
11// same seed — a property the tests assert. The solar accumulator is two
12// per-face vectors and needs no layout machinery.
