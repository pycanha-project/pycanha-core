Detailed Description

Crank-Nicolson transient that also propagates the derivatives of the diffusive temperatures with respect to the parameters selected in Formulas::parameters_with_derivatives(). The derivatives are stored as the JAC attribute of the output model, at the same output times as the temperatures. The sensitivity solve uses the factors of the last step's matrix, so reuse_factors does not apply. initialize() throws std::invalid_argument when no derivative parameter is selected.
