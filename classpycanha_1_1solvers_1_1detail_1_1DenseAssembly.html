Detailed Description

Writes the dense matrix A + diag(D) of a network.

A is the linearized matrix described in LinearizedNetwork, stored as a full n x n array.

A + diag(diagonal) at the temperatures t (t3 = 4 sigma t^3) into matrix, and 0.75 A_rad t into radiation. An empty diagonal adds nothing. With rewrite the matrix holds anything (a factorization took its storage) and is written in full; otherwise it holds what the previous call wrote. Returns false only when the values are known to be those of the previous call.
