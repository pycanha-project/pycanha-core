Detailed Description

Thermo-optical surface properties of a material.

Restored from the legacy gmm with full fidelity: six optical degrees of freedom held as an array, ordered as [0] emissivity_ir [1] specular_reflectivity_ir [2] transmissivity_ir [3] absorptivity_solar [4] specular_reflectivity_solar [5] transmissivity_solar The default is a black body {1, 0, 0, 1, 0, 0}. Every value must lie in [0, 1]; violations throw std::invalid_argument.

Named convenience accessors (emissivity_ir / absorptivity_solar) and the two-argument constructor address indices [0] and [3]; the remaining four degrees of freedom default to 0 unless set via the full array API.
