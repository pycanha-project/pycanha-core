Detailed Description

Aggregates the thermal coupling matrices for a network of Nodes.

The class preserves the legacy public interface while delegating the actual matrix management to a composed CouplingMatrices instance.

std::span< const NodeNum > node_nums_2,

CouplingMerge merge = CouplingMerge::OVERWRITE )

General bulk insertion by node number.

The arrays are read in place, never copied, and every value is written once, into the matrix storage. Entry i couples node_nums_1[i] and node_nums_2[i], in either order. Dropped, and reported: an unknown node, the same node on both ends, a negative or non-finite value, and the whole call when the three arrays differ in length.

The fastest path is taken per block (dd, db, bb) when the call's entries of that block are sorted by (lower internal index, higher internal index) and come after every coupling already stored there – for an all-diffusive model simply "sorted by (smaller node number, larger node number)", as a builder or a numpy grid produces them. They are then appended directly, O(k). Otherwise they are sorted (O(k) by row plus a sort inside each row) and merged into the block in place, O(stored + k). A coupling that already exists, or that the call gives more than once, is resolved by merge.

Pointers into the coupling values (get_coupling_value_ref) are invalidated.
