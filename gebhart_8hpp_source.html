11// CPU Gebhart services (no Vulkan, built unconditionally): re-derive
12// radiative exchange factors from a geometric VF matrix and per-face-slot
13// band emissivities without re-tracing — the diffuse-gray fast path. The
14// MCRT exchange kernel computes the same quantity directly, so the two
15// paths are cross-checkable within Monte-Carlo tolerance.
16
17// Face-level Gebhart factors B = (I - F R)^-1 F E with R = diag(1 - eps),
18// E = diag(eps). The dense solve limits this to small models (the guard
19// throws above ~20k face slots, pointing at gebhart_node_factors).
20//
21// `space_fraction_policy` decides what each row's deficit (1 - row_sum)
22// means: 1.0 (default) treats it as a real view to space; 0.0 renormalizes
23// the row to sum to one (closed-enclosure assumption, i.e. the deficit is
24// Monte-Carlo noise); values in between scale the deficit accordingly.
25[[nodiscard]] SparseF64 gebhart_factors(const SparseF64& vf,
26 const Eigen::VectorXd& emissivity,
27 double space_fraction_policy = 1.0);
28
29// Node-level Gebhart GR matrix (m^2) for ANY model size:
30// GR(m, n) = sum_{i in m} sum_{j in n} A_i eps_i B_ij, computed with one
31// sparse factorization of (I - F R) and n_nodes sparse solves instead of a
32// dense inverse. Rows/cols are indexed by position in
33// aggregate_nodes(node_numbers); NO_NODE slots are dropped.
34[[nodiscard]] SparseF64 gebhart_node_factors(
35 const SparseF64& vf, const Eigen::VectorXd& emissivity,
36 std::span<const NodeNum> node_numbers, std::span<const double> face_areas,
37 double space_fraction_policy = 1.0);
