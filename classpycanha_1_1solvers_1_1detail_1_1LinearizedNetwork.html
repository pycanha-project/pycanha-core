Detailed Description

The linearized matrix of the diffusive nodes and its factorization.

linearize() sets A = -K, with K the conductance matrix with the radiation linearized at the given temperatures: K_ij = GL_ij + GR_ij 4 sigma Tj^3 off the diagonal, and minus the sum of the couplings of row i, boundary couplings included, on it. The network holds A + D, with D the diagonal the solver passes to linearize() (2C/dt in a transient). A is symmetric positive definite without radiative couplings.

With fixed_couplings the matrix is built from constants read once per solve(); otherwise every linearize() reads the couplings again. Either way the network knows when its factors belong to the current matrix.
