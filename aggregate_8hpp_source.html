32// out(m, n) = sum over faces i of node m, j of node n of face_matrix(i, j),
33// with i <= j and the result canonicalised into the UPPER TRIANGLE.
34//
35// The input is the extensive (m^2) face matrix a VF result stores, so the
36// reduction is a plain sum — there is no area weighting to apply, and
37// applying one anyway would scale every entry by a further A_i and yield a
38// dimensionally meaningless m^4 matrix that still solves and still looks
39// plausible. To condense an INTENSIVE matrix (Gebhart factors, say), scale
40// its rows by the face areas first.
41//
42// Two things do not survive the mapping from faces to nodes, and both are
43// handled here:
44// - node numbers are assigned independently of face-slot numbering, so a
45// face pair i < j can land on a node pair m > n; every write is
46// canonicalised to (min(m, n), max(m, n)) or the output would be an
47// arbitrary mix of both triangles rather than a triangle,
48// - pairs whose faces share a node fall on the diagonal. A node is
49// isothermal by definition, so radiation it exchanges with itself
50// transports no heat and the coupling network has no slot for it; the
51// diagonal is dropped and its total reported.
52//
53// Matrix results carry the virtual space/inactive/lost bucket columns after
54// the real face columns. This overload drops them (missing column labels
55// count as NO_NODE); use the row/column overload below to map a bucket to a
56// real node (e.g. the space node).
57[[nodiscard]] AggregateResult aggregate_matrix(
58 const SparseMatrix& face_matrix, std::span<const NodeNum> node_numbers);
59
60// General form: rows and columns labeled independently. `row_node_numbers`
61// has one entry per matrix row, `col_node_numbers` one per matrix COLUMN —
62// including the virtual bucket columns, so those can be assigned nodes or
63// NO_NODE. Output rows/cols are indexed by position in
64// aggregate_nodes(row_node_numbers) / aggregate_nodes(col_node_numbers).
65//
66// Rows and columns carry independent label sets here, so there is no
67// triangle to canonicalise into and no diagonal that means self-coupling:
68// this overload sums every mapped entry exactly where it lands and reports
69// nothing discarded.
70[[nodiscard]] AggregateResult aggregate_matrix(
71 const SparseMatrix& face_matrix, std::span<const NodeNum> row_node_numbers,
72 std::span<const NodeNum> col_node_numbers);
